# Anti-scam trainer

Учебный тренажёр безопасного поведения в чатах классифайда. Пользователь проходит сценарий в роли покупателя или продавца, общается с виртуальным собеседником и учится замечать признаки мошенничества до того, как потеряет деньги или данные.

Сейчас в репозитории находится ранний каркас проекта: Go-бэкенд с базовым CRUD, схема PostgreSQL и локальная инфраструктура для PostgreSQL и Ollama. Фронтенд и интеграция бэкенда с моделью ещё не реализованы.
