# Anti-scam trainer

Учебный тренажёр безопасного поведения в чатах классифайда. Пользователь проходит сценарий в роли покупателя или продавца, общается с виртуальным собеседником и учится замечать признаки мошенничества до того, как потеряет деньги или данные.

Репозиторий содержит Go-бэкенд полного игрового цикла MVP, PostgreSQL, локальный qwen3:8b через Ollama и Nginx gateway для веб-клиента. Реализованы четыре Уровня двух ролевых веток, Свободная игра, аутентификация и сохраняемый Прогресс.
