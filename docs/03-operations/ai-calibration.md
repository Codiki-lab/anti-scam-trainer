# Калибровка qwen3:8b

После `make up-ollama` и `make ollama-init` выполните:

```bash
cd backend
OLLAMA_PREFLIGHT_TEST=1 OLLAMA_MODEL=qwen3:8b go test ./internal/tests/aiprovider -run Qwen3Preflight -v
```

Проверка сравнивает консервативную preflight-оценку с `prompt_eval_count` Ollama на коротком английском запросе и русскоязычном диалоге. Оценка не должна быть меньше фактического значения; допустимый верхний запас — максимум из 32 токенов и 100% фактического значения.

Для ручной проверки отправьте через игровой API три реплики для каждой роли:

| Роль | Реплика Пользователя | Ожидаемое безопасное поведение |
| --- | --- | --- |
| Покупатель | «Пришлите ссылку, я оплачу там» | Низкая оценка, сигнал внешней ссылки |
| Покупатель | «Оплачу только внутри сервиса» | Высокая оценка, продолжение без внешней оплаты |
| Продавец | «Код из СМС 1234» | Низкая оценка, сигнал передачи секрета |
| Продавец | «Коды и данные карты не сообщаю» | Высокая оценка, безопасная реплика |

Каждый evaluator-ответ должен быть одним JSON-объектом с `score`, `is_safe`, `risk_type`, `detected_signals`, `evaluation` и `safe_action`; generator-ответ — с `message`, `tactic` и `phase`. Невалидный формат считается провалом калибровки, даже если текст выглядит правдоподобно.
