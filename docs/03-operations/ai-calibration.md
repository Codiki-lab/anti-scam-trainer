# Калибровка qwen3:8b

После `make up-ollama` и `make ollama-init` выполните:

```bash
cd backend
OLLAMA_PREFLIGHT_TEST=1 OLLAMA_MODEL=qwen3:8b go test ./internal/tests/aiprovider -run Qwen3Preflight -v
```

Проверка сравнивает консервативную preflight-оценку с `prompt_eval_count` Ollama на коротком английском запросе и русскоязычном диалоге. Оценка не должна быть меньше фактического значения; допустимый верхний запас — максимум из 32 токенов и 100% фактического значения.

Для ручной проверки отправьте через игровой API три реплики для каждой роли:

| Роль | Реплика Пользователя | Ожидаемое безопасное поведение |
| --- | --- | --- |
| Покупатель | «Пришлите ссылку, я оплачу там» | Низкая оценка, сигнал внешней ссылки |
| Покупатель | «Оплачу только внутри сервиса» | Высокая оценка, продолжение без внешней оплаты |
| Продавец | «Код из СМС 1234» | Низкая оценка, сигнал передачи секрета |
| Продавец | «Коды и данные карты не сообщаю» | Высокая оценка, безопасная реплика |
| Любая | «Не открою ссылку» | Быстрая максимальная оценка — 100 Баллов — без вызова Ollama |
| Любая | «Нет, не буду так делать» | Смысловая проверка: отказ от опасной просьбы получает высокую оценку, отказ от штатной проверки — нет |
| Любая | «Не буду, но потом всё-таки открою ссылку» | Низкая оценка после смысловой проверки Ollama |

Каждый evaluator-ответ должен быть одним JSON-объектом с `score`, `is_safe`, `risk_type`, `detected_signals`, `evaluation` и `safe_action`. `is_safe=true` допустим только для `score=3..4`. Невалидный или противоречивый формат считается провалом калибровки, даже если текст выглядит правдоподобно. Generator модель не вызывает.

`model_cases`, доля fallback, качество классификации и p95 считаются по фактически зафиксированным обращениям к evaluator-модели. Набор содержит контекстные безопасные и рискованные формулировки, намеренно не распознаваемые локальным fast path. Локальные решения проверяются отдельными assertions, но не улучшают модельные показатели искусственно. `structured_json_rate` независимо измеряет долю валидных schema-ответов среди всех model calls, включая repair-вызовы; эта метрика не вычисляется из доли fallback.

Закрытый Набор оценки содержит 132 production-подобных случая с policy соответствующей Ролевой ветки, контекстом Шага и последней репликой Виртуального собеседника. Локальные решения для явных безопасных и рискованных действий, а также prompt injection, не входят в знаменатель валидности structured JSON и не считаются fallback-ами.
