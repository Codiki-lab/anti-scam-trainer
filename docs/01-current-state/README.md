# Текущее состояние

На 9 августа 2026 года репозиторий содержит полный бэкенд игрового цикла MVP и локальную инфраструктуру демонстрации.

## Что уже есть

| Область | Состояние |
| --- | --- |
| HTTP-сервер | Работает на стандартном `net/http`, порт задаётся через `PORT`; в Compose запускается после миграций |
| Пользователи | CRUD для `users` |
| Сценарии | Администратор управляет Сценариями, Шагами, вариантами, AI-инструкциями и рубриками; опубликованы восемь стартовых Сценариев |
| Прохождения | Реализованы Уровни 1–4, история Сообщений, mixed/free-text ответы, атомарный итог, монотонный Прогресс и Свободная игра |
| PostgreSQL | Описан в Docker Compose; versioned-миграция создаёт начальную SQL-схему |
| Ollama | Описан отдельным Compose-файлом, модель загружается по `OLLAMA_MODEL` |
| AI provider | Игровой сервис вызывает qwen3:8b через Ollama, ограничивает историю и строго валидирует JSON до записи состояния |
| Веб-интеграция | Credentialed CORS ограничен localhost-origin; Nginx на `localhost:3000` проксирует `/api` и отдаёт `frontend/dist` |
| HTTP middleware | Добавляет `X-Request-ID`, журналирует запросы, преобразует непойманную панику в `500` и записывает задержку обработки |
| Проверка состояния | `GET /api/v1/health` возвращает `{"status":"ok"}` |
| Документация API | Защищённые HTTP Basic Auth Swagger UI (`/swagger/`) и OpenAPI v1 (`/openapi/v1.yaml`); канонический файл — `backend/openapi/v1/openapi.yaml` |

Бэкенд организован тремя контейнерами в `backend/internal`: `core` с общими правилами и техническими адаптерами, `features` с продуктовыми возможностями `users`, `scenarios`, `attempts` и `progress`, а также `tests` с проверками их публичных интерфейсов. В каждой продуктовой возможности HTTP-адаптер, сервис и PostgreSQL-репозиторий разделены физически. `core/app` — composition root: он создаёт соединение с БД, связывает конкретные адаптеры и регистрирует их маршруты в `core/server/router` под `/api/v1`.

## Чего пока нет

- пользовательского интерфейса админки;
- достижений и рейтинга;
- облачного размещения.

## Известные технические ограничения

1. Пользовательский веб-клиент поставляется отдельно; gateway ожидает production-сборку в `frontend/dist`.
2. Начальная схема находится в обратимой versioned-миграции `000001_initial_schema`. Контейнер миграций применяет её и все последующие миграции перед запуском API в Compose.
3. Калибровочный тест qwen3:8b требует локального Ollama и запускается только по `OLLAMA_PREFLIGHT_TEST=1`.

Эти пункты описывают фактическое состояние, а не утверждённый план исправлений.

## Проверенный минимум

Команда ниже запускает тесты доменных правил и HTTP-контракта без PostgreSQL:

```bash
cd backend
go test ./...
```

Тесты домена проверяют допустимые переходы статуса прохождения и границы звёзд. HTTP-тесты собирают роутер с тестовыми реализациями репозиториев и проверяют наблюдаемое поведение существующего CRUD.
