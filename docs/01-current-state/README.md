# Текущее состояние

На 7 августа 2026 года репозиторий содержит каркас бэкенда и локальной инфраструктуры. Основной пользовательский сценарий тренажёра ещё не собран целиком.

Согласованное, но ещё не реализованное поведение описано отдельно в документах [«Продукт и границы MVP»](product.md) и [«Игровая прогрессия»](game-design.md).

## Что уже есть

| Область | Состояние |
| --- | --- |
| HTTP-сервер | Работает на стандартном `net/http`, порт задаётся через `PORT` |
| Пользователи | CRUD для `users` |
| Сценарии | CRUD для `chats` |
| Прохождения | CRUD для `chat_sessions` |
| PostgreSQL | Описан в Docker Compose, подготовлена начальная SQL-схема |
| Ollama | Описан отдельным Compose-файлом, модель загружается по `OLLAMA_MODEL` |
| Проверка состояния | `GET /health` возвращает `{"status":"ok"}` |

В коде соблюдается базовое разделение на модели, сервисы и репозитории. Создание соединения с БД, роутера и приложения собрано в `app_builder`.

## Чего пока нет

- фронтенд-приложения;
- HTTP-методов для шагов сценария, вариантов ответа и сообщений;
- игрового цикла «начать сценарий → ответить → получить следующую реплику → завершить»;
- AI-провайдера и обращения к Ollama из Go-кода;
- проверки и оценки свободного ответа;
- авторизации и привязки запроса к текущему пользователю;
- автоматических тестов;
- готовых Docker-образов бэкенда и фронтенда;
- настроенного Nginx.

## Известные технические ограничения

1. Бэкенд ожидает переменные `POSTGRES_NAME`, `POSTGRES_HOST` и `POSTGRES_PORT`, а пример окружения содержит `POSTGRES_DB` и не содержит адреса БД. Без дополнительных переменных соединение не настроится.
2. `golang-migrate` ожидает миграции с суффиксами `.up.sql` и `.down.sql`, а текущий файл называется `init.sql`. Поэтому `make migrate-up` пока не применяет эту схему как обычную миграцию.
3. Уникальный индекс `chat_options(chat_id, step_number)` позволяет сохранить только один вариант ответа на шаг. Для сценария с несколькими вариантами связь придётся изменить.
4. В SQL-схеме есть сущности, для которых ещё нет моделей и репозиториев: шаги, варианты ответа, сообщения, достижения, статистика и рейтинг.
5. `services/db.go` дублирует инициализацию БД из `app_builder` и не используется точкой входа.
6. `make lint` и `make test` всегда вызывают команды фронтенда, хотя `frontend/package.json` пока отсутствует.

Эти пункты описывают фактическое состояние, а не утверждённый план исправлений.

## Проверенный минимум

Команда ниже успешно компилирует все Go-пакеты:

```bash
cd backend
go test ./...
```

Тестовых файлов пока нет, поэтому эта проверка подтверждает сборку, но не корректность бизнес-логики.
