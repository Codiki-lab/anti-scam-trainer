# Anti-scam trainer — командное решение

## Проблема

Мошенничество в объявлениях часто маскируется под обычную сделку: собеседник присылает поддельную ссылку, просит оплатить товар вне платформы, назвать код из SMS или перейти в сторонний мессенджер. Пользователь может знать отдельные правила безопасности, но не распознать их нарушение в контексте живого диалога. Пассивной памятки недостаточно — нужен безопасный способ потренировать принятие решений до реальной сделки.

## Идея решения

**Anti-scam trainer** — интерактивный тренажёр для покупателя и продавца. Пользователь проходит короткий учебный цикл: изучает Теорию, подтверждает знания в Quiz и применяет их в диалоговых Сценариях, похожих на настоящую переписку. После каждого Прохождения он получает Result с понятным разбором решений, сигналов риска и безопасных действий.

Вместо разовой проверки памяти продукт формирует навык: сложность растёт постепенно, а после завершения ролевой ветки Свободная игра становится рекомендуемым следующим действием. Этот отдельный режим открывается для роли после прохождения Уровня 4 хотя бы на одну Звезду во всех шести Темах. Ежедневное задание «мошенник или нет», Прогресс, Звёзды, Серия дней и Достижения поддерживают регулярную практику.

## MVP

За время хакатона команда реализовала:

- регистрацию, вход и защищённую cookie-аутентификацию;
- две ролевые ветки — покупателя и продавца;
- 6 Тем для каждой роли, в каждой — пять блоков Теории и Quiz из пяти вопросов;
- четыре последовательных Уровня диалоговых тренировок;
- готовые ответы, смешанный режим и свободный ввод;
- локальную `qwen3:8b` через Ollama для старших Уровней и Свободной игры;
- Свободную игру для каждой роли после завершения основной практики;
- Ежедневное задание, Result, Прогресс, Звёзды, Серию дней и Достижения;
- React-интерфейс основного пользовательского пути и web-админку учебного контента;
- Go API, PostgreSQL, OpenAPI, миграции, Docker Compose и автоматические проверки.

## Ценность решения для Авито

Решение превращает безопасность из справочного материала в практический навык. Пользователь не просто читает запрет, а несколько раз принимает решение в ситуации, похожей на реальную сделку, и сразу видит последствия. Это может снизить долю рискованных действий, повысить уверенность новых покупателей и продавцов и помочь профилактике мошенничества до обращения в поддержку.

Тренажёр можно встроить в Авито как:

- часть онбординга нового Пользователя;
- короткую тренировку перед первой сделкой;
- персональную рекомендацию после обнаружения рискованного действия;
- регулярное Ежедневное задание;
- образовательный модуль для новых мошеннических паттернов.

Контент отделён от кода и управляется через административный API. Новые Темы и Сценарии можно добавлять по данным реальных обращений, не переписывая игровой цикл. Локальная модель получает только ограниченный предметный контекст и возвращает структурированный ответ, что делает решение контролируемым и пригодным для дальнейшей продуктовой проверки.
