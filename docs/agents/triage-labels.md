# Метки triage

Инженерные навыки используют пять канонических ролей. Таблица сопоставляет их фактическим меткам GitHub Issues этого репозитория.

| Каноническая роль | Метка в GitHub | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Задачу должен оценить мейнтейнер. |
| `needs-info` | `needs-info` | Нужна дополнительная информация от автора. |
| `ready-for-agent` | `ready-for-agent` | Задача полностью определена и готова для автономного агента. |
| `ready-for-human` | `ready-for-human` | Требуется реализация человеком. |
| `wontfix` | `wontfix` | Задача не будет выполняться. |

Если навык упоминает каноническую роль, применяйте соответствующую ей метку из таблицы. При изменении принятого словаря меток обновите правый столбец.
