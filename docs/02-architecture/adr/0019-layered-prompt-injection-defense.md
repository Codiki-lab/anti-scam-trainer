# ADR-0019: многослойная защита AI от prompt injection

- Статус: принято
- Дата: 2026-08-13
- Уточняет: ADR-0014, ADR-0016

## Контекст

Ответ пользователя может содержать инструкции для модели, просьбы раскрыть policy или изменить оценку. Одного системного промпта недостаточно, а model output не обладает авторитетом для изменения игрового состояния.

## Решение

Backend передаёт Ответ пользователя в отдельном ограниченном по длине поле structured-входа и маркирует его недоверенными данными. Generator не получает этот текст, если он не нужен для следующей реплики. Server-side правила сохраняют единоличный контроль над Баллом, Звёздами, фазой, завершением и Прогрессом; результат модели проходит schema/policy-валидацию до записи. Явная попытка управлять моделью получает нейтральную учебную обратную связь без раскрытия внутренних инструкций. Набор оценки содержит русскоязычные и смешанные prompt injection-примеры как регрессионные случаи.

## Последствия

- Инъекция не может повысить Балл, открыть Уровень или раскрыть policy.
- Защита требует проверок на входной границе и регулярного прогона Набора оценки, а не только настройки промпта.
