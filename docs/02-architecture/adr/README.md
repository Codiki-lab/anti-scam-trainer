# Architecture Decision Records

ADR фиксирует архитектурное решение вместе с причиной и последствиями. Он отвечает не только на вопрос «как устроено», но и на вопрос «почему сделали именно так».

## Статусы

- **Предложено** — вариант вынесен на обсуждение.
- **Принято** — команда договорилась следовать решению.
- **Заменено** — появилось новое ADR, которое заменяет это решение.
- **Отклонено** — решение обсуждалось, но не принято.

Принятый ADR не переписывают задним числом. Если решение изменилось, создают новую запись и связывают её с предыдущей.
