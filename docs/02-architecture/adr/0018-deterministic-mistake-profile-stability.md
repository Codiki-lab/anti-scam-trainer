# ADR-0018: детерминированная устойчивость Профиля ошибок

- Статус: принято
- Дата: 2026-08-13

## Контекст

Персональная рекомендация и микро-вопрос не должны появляться из-за одной случайной ошибки, а улучшение Пользователя должно уменьшать приоритет старого риска. Модель не должна самостоятельно решать, какой паттерн считать повторяющимся.

## Решение

Backend помечает рискованный паттерн устойчивым при двух совпадениях среди пяти последних завершённых Прохождений либо при трёх совпадениях за всё время. Два безопасных Ответа по паттерну снижают его приоритет. На этом детерминированном результате строятся рекомендации и необязательные микро-вопросы; закрытые Уровни никогда не открываются из-за Профиля ошибок.

## Последствия

- Рекомендации устойчивы, объяснимы и не зависят от суждения модели.
- Для реализации понадобятся агрегированные сигналы по завершённым Прохождениям без хранения полной истории диалогов.
