# ADR-0011: разовая несовместимая замена API v1

- Статус: принято
- Дата: 2026-08-09
- Уточняет ADR-0010

## Контекст

Ранний `/api/v1` появился до реального frontend-потребителя и не мог полностью восстановить 11 экранов: не было Тем, Теории, Quiz, Dashboard, Result, тематического Прогресса, единого формата ошибок и защиты от устаревшего Шага сценария. Параллельная поддержка временного контракта создала бы лишний слой совместимости без существующего клиента.

## Решение

Issue #49 выполняет одну явно согласованную несовместимую замену `/api/v1`. Канонический `backend/openapi/v1/openapi.yaml` обновляется раньше либо одновременно с handler/DTO и контрактными тестами. Старые игровые DTO не поддерживаются параллельно.

После этой замены любое несовместимое изменение публикуется только как новая версия `/api/v2` с отдельным OpenAPI-файлом и возможностью сосуществования версий. Совместимые расширения v1 допустимы при синхронном обновлении OpenAPI и тестов.

## Последствия

- Frontend получает один полный контракт без скрытых допущений.
- Этот ADR нельзя использовать как общее разрешение ломать v1 повторно.
- Следующая несовместимость требует маршрутов, спецификации и миграционного плана v2.
