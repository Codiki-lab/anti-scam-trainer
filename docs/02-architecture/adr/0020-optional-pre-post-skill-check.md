# ADR-0020: необязательная Проверка навыка до и после обучения

- Статус: принято
- Дата: 2026-08-13

## Контекст

Балл за отдельное Прохождение не показывает, стал ли Пользователь лучше распознавать риск в новом контексте. Для демонстрации ценности обучения нужна независимая и неинвазивная метрика результата.

## Решение

Тренажёр предлагает необязательную Проверку навыка: один Снимок диалога до Темы и другой, не похожий на первый, после обучения. Для каждой Темы и Ролевой ветки сервер хранит 2–3 сопоставимые пары Снимков и при старте сохраняет случайно выбранную пару; AI при подборе не вызывается. Система сравнивает вердикты Пользователя и повторяющиеся рискованные паттерны. Проверка навыка не является Quiz или Прохождением, не меняет Балл, Звёзды, Прогресс и доступность Уровней.

## Последствия

- Команда получает измеримый показатель изменения навыка, а не только активности в тренажёре.
- Для честного сравнения требуются пары сопоставимых, но не идентичных Снимков диалога.
