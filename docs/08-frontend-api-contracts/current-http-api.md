# Текущий HTTP API

Канонический подробный контракт фактически реализованного API `v1` — OpenAPI 3.1-спецификация: [`backend/openapi/v1/openapi.yaml`](../../backend/openapi/v1/openapi.yaml). Она доступна работающему приложению по защищённому адресу `/openapi/v1.yaml`.

Интерактивное представление контракта открывается по `/swagger/`. Оба адреса требуют отдельную HTTP Basic Auth аутентификацию из `SWAGGER_USERNAME` и `SWAGGER_PASSWORD`; это не учётная запись Пользователя и не JWT-cookie `access_token`.

## Общие правила

- Базовый адрес локального API: `http://localhost:8080`; продуктовые маршруты используют префикс `/api/v1`.
- Каждый ответ содержит `X-Request-ID`.
- Открыты только health-check, регистрация, вход и выход. Остальные методы тренажёра требуют подписанную JWT-cookie `access_token`.
- Роль доступа учётной записи (`user` или `admin`) не является ролью Пользователя в Сценарии (`buyer` или `seller`).
- Прохождения всегда принадлежат текущему Пользователю из JWT: `user_id` не передаётся в теле и не возвращается в ответах.

При следующей несовместимой версии API создаётся отдельный OpenAPI-файл и URL `/openapi/vN.yaml`; Swagger UI показывает доступные версии переключателем.

## Игровой цикл уровней 1–2

- `GET /api/v1/training/levels?role=buyer|seller` возвращает уровни ролевой ветки и их Открытость.
- `POST /api/v1/training/levels/{level}/start?role=buyer|seller` начинает или возобновляет Прохождение, возвращая текущий Шаг сценария, историю Сообщений и сохранённые Ответы пользователя.
- `POST /api/v1/attempts/{id}/answers` принимает вариант текущего Шага сценария; последний ответ возвращает Балл, Звёзды и разбор.
- `POST /api/v1/attempts/{id}/abandon` бросает собственное незавершённое Прохождение.

Учебным контентом управляет только роль доступа `admin` через `/api/v1/admin/scenarios` и вложенные ресурсы Шагов сценария и вариантов. Подробные тела запросов, ответы и коды статуса — в канонической OpenAPI-спецификации.

Контракт пока не включает восстановление пароля, уровни 3–4, Свободную игру, достижения и статистику.
